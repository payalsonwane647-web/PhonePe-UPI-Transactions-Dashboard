# PhonePe-UPI-Transactions-Dashboard

Project Overview

This project is an interactive PhonePe UPI Transactions Dashboard developed in Microsoft Excel to analyze transaction performance and provide business insights. The dashboard presents key metrics, transaction trends, and user behavior through dynamic visualizations and interactive filters.

Features
Interactive dashboard with slicers for dynamic filtering.
KPI cards for Total Transactions, Transaction Amount, Cashback, Success Rate, and Suspected Fraud.
Transaction analysis by UPI app, bank, state, transaction type, and status.
Daily transaction trend analysis and hourly transaction heatmap.
Interactive charts, maps, and PivotTables for data-driven insights.

Tools & Technologies
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Conditional Formatting
Maps & Heatmap
Data Visualization

Key Insights
Identifies transaction patterns across different UPI applications.
Monitors transaction success and failure rates.
Analyzes transaction volume by state, bank, and transaction type.
Tracks daily and hourly transaction trends to support business decisions.
